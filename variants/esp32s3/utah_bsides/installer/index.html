Utah BSides badge installer

Install the latest badge firmware from this page.

This big update resets the badge. It changes how the badge's memory is laid out (for WiFi updates later), so the badge's Meshtastic settings, keys, channels and messages start fresh. Note any channel settings you want to keep first. After this one, updates happen over WiFi from the badge itself and keep your settings.
  1. Use Chrome or Edge on a computer (not a phone; Firefox and Safari can't do this).
  2. Plug the badge in with a USB data cable.
  3. Press the button, pick the badge's port (often "USB JTAG/serial debug unit"), and choose Install. When asked, choose to erase the device.
  4. Wait about two minutes until it says it's done. The badge restarts by itself.
This browser can't install firmware. Use Chrome or Edge on a computer. This page has to be opened over https.

If the badge isn't found: hold its BOOT button, tap RESET, let go of BOOT, then try again.

Later updates (no computer needed)
  1. Download firmware-utah_bsides-…update.bin from the latest badge release to your phone.
  2. On the badge: hold * for the menu, choose Badge WiFi (phone).
  3. Join the WiFi network shown on the badge with the password shown, open the address shown, go to Update and send the file.
  4. Press # on the badge to install. It only accepts updates signed by the badge team.
